# Smart Parking Platform

Semester project for Software Project Management.

## Project Overview

The Smart Parking Platform is a proposed web and mobile system designed
to help drivers locate, reserve, navigate to, and pay for parking in
participating parking garages.

The platform also provides parking operators with tools for managing
facilities, pricing, parking availability, reservations, and reporting.
